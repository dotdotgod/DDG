# 숫자 탭과 기본 키맵

상태: **보관(아카이브)** — 구현 완료(N0–N3), macOS 실기 검증(N4)만 별도 추적. [설계](DESIGN.md) · [실행 태스크](TASKS.md) · [플래닝 보고](../../report/2026-11-22/numbered-tabs/PLANNING.md)

기존 GPUI 터미널의 탭 라벨을 왼쪽부터 숫자로 표시하고 생성·닫기·순환 이동과 숫자로 직접 이동을 기본 키맵으로 제공한다. macOS arm64 실기 검증만 이번 범위다. 앱 내 키맵, 사용자 편집, PTY 및 렌더러 개편은 제외한다.
