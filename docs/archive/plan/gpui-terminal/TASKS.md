## G5 실제 환경 확인

macOS 버전, arm64, Rust/GPUI/Ghostty/Pi 버전, IME·폰트를 기록한다. 실행마다 임시 탭과 합성 데이터만 쓴다.

1. 깨끗한 arm64 개발 환경에서 기록한 Cargo 명령으로 빌드·실행한다. 자동 기본 셸과 독립 탭이 열려야 한다.
2. 탭마다 다른 PID와 출력 표식을 확인한다. 출력이 많은 숨은 탭을 닫는 동안 포커스가 유지되고 UI가 멈추지 않으며 대상 PID가 회수되어야 한다. 정상 종료의 마지막 출력 표식은 종료 표시보다 앞서야 하며 의도적으로 닫은 탭의 출력은 폐기할 수 있다. 앱을 닫은 후 소유 셸 PID를 다시 확인한다.
3. 같은 Pi 버전으로 Enter 제출/Shift+Enter 줄바꿈, 한글 조합·취소·전환 시 중복이나 다른 탭 입력 없음, VoiceOver의 선택·오류·복구 조작을 확인한다. 복붙·선택·스크롤·대체 화면·Retina·넓은 문자·P10k와 `stty size`를 기존 앱과 비교한다.
4. 임시 클립보드 표식으로 미승인 OSC 읽기/쓰기가 효과를 내지 않으며 명시적 복붙은 동작하는지 확인한다. 시험 탭과 임시 데이터를 정리한다. 증거에는 실제 세션 내용이나 사용자 클립보드를 남기지 않는다.
5. 전환 전 사용자에게 작업 저장과 기존 셸 정상 종료를 안내한다. 복구 기준에서 기존 앱이 시작되는 것을 확인한다. 롤백은 앱 소스/빌드 복구이며 실행 중 셸 복원이 아니다.

비가역 변경은 승인 전 대기하되 G1–G5의 허용된 독립 작업은 진행한다. 머지는 범위 밖이며 Git 저장소가 확인되고 별도 승인된 경우에만 한다. 해당 커밋 본문에는 계획·보고 경로, 선택·대안, 승인·검증과 잔여 위험을 남긴다.
