# GPUI 전환 설계

범위: macOS arm64 개발 실행, 현행 앱 전체 교체. 기존 제품의 원격·3D·재접속 목표는 별도 작업이다.

## UX와 Presentation

```text
+-------------------+-----------------------------------+
| [g] Ddg           | [Terminal 1*] [Terminal 2]  +  x   |
| Local terminal    +-----------------------------------+
| Status / error    | shell grid, cursor and scrollback |
| [Restart]         |                                   |
+-------------------+-----------------------------------+
```

첫 실행에 기본 셸 하나를 열고, 이후에는 독립 탭을 추가한다. 기존 디자인, 드래그·키보드 사이드바 조절, 탭과 기존 단축키를 유지한다. 선택 탭의 상태를 표시하며, 종료/실패 탭은 마지막 화면과 이유를 남기고 같은 탭에서 새 셸로 재시작한다. 닫기는 기존처럼 확인 없이 대상 탭을 종료한다. 실패하면 탭을 유지하면서 오류를 표시한다. 성공하면 오른쪽 탭, 왼쪽 탭, 마지막이면 빈 화면과 `+` 순서로 이동한다. 비동기 이벤트는 사용자가 그사이 선택한 탭과 포커스를 빼앗지 않는다. 앱 초기화 실패는 탭 오류와 구분한다.

선택된 활성 터미널만 키·붙여넣기를 받는다. 키보드와 VoiceOver로 탭과 상태, 재시작, 너비 조절에 접근할 수 있어야 한다. 화살표로 탭을 탐색하면 탭에 포커스를 남긴다. OS/VoiceOver 및 IME가 소비한 이벤트를 앱이나 셸에 중복 전달하지 않는다. 조합은 해당 실행과 포커스에 귀속한다. 커서에 조합을 표시하고 확정 텍스트만 한 번 보내며, 탭 전환/blur 시 취소하고 늦은 콜백을 버린다.

## 실행과 데이터 계약

GPUI 창 모델이 탭 순서와 선택을, 탭이 VT 화면·스크롤백과 상태를, 실행이 PTY/자식 프로세스를 소유한다. Tauri IPC 대신 내부 `Start/Write/Resize/Close`와 `Data/Exit/Error`를 탭 및 실행 ID로 연결한다. 기존 기본 셸과 환경, 최대 16개 탭 및 PTY 크기·쓰기 청크 제한을 이식한다. 재시작은 새 실행 ID와 빈 VT 상태를 사용한다. 이전 실행에서 늦게 온 입력·출력·종료는 실행 경계에서 걸러낸다.

PTY I/O와 자식 대기는 UI 밖에서 수행한다. 원시 출력을 순서대로 VT에 전달하고 최종 출력 이후 종료를 표시한다. 유한 큐와 백프레셔를 사용하되 종료 시 취소가 가능해야 하며, 살아 있는 실행에서 출력 유실을 숨기지 않는다. VT 응답과 키·붙여넣기는 실행별 단일 writer에서 직렬화한다. 숨은 탭도 출력을 소비한다. 표시될 때 현재 셀 크기에 맞춰 PTY와 VT를 함께 갱신한다. 닫기/앱 종료 시 소유한 자식을 정리·회수한다. 의도적으로 분리된 작업까지 종료한다고 보장하지 않는다.

PTY 출력은 신뢰하지 않는 VT 데이터다. FFI 경계에서 길이·반환값·수명 및 그리드 값을 확인하고 내부 계약은 중복 검증하지 않는다. VT 출력이 앱 명령, 셸 상태 판정, OSC 클립보드 조작을 일으키지 않게 한다. 사용자가 실행하는 복사/붙여넣기는 유지한다. DB 조회와 외부 서비스 응답은 범위 밖이고 별도 로그·네트워크·재접속·개발 리로드 재생은 추가하지 않는다.

## 리뷰 반영 사항

- 닫기는 지정 실행의 I/O 정리와 자식 회수가 확인되어야 성공한다. 자연 종료와 겹치면 회수된 실행에 대한 닫기를 성공으로 처리한다. 실패는 탭을 보존한다. 포화 시 UI/VT가 writer 공간을 동기 대기하지 않도록 하고, 명시적 포화 오류 또는 순서 보존 재개를 사용한다. 닫기 취소 경로는 데이터 큐와 독립적이다.
- OSC 콜백은 읽기·쓰기를 포함한 호스트 클립보드 효과를 기본 차단한다. 같은 실행의 프로토콜 응답과 명시적 사용자 복붙은 별개다. 진단에 입력·출력 원문을 남기지 않는다.
- 탭 목록에 포커스가 있을 때 셸 입력을 차단한다. 선택된 탭에서 활성화 키로 해당 터미널 또는 재시작 컨트롤에 진입하고, 표준 포커스 순회로 나올 수 있어야 한다. VoiceOver에서 선택·종료·실패와 복구 조작을 확인한다.

## 검증 기준

- 유닛: 모드별 Enter/Shift+Enter의 바이트를 Ghostty 프로토콜 사례와 대조. 분할 UTF-8/VT와 단일 청크의 결과 일치. 실행 교체·백그라운드 종료·닫기 실패에서 선택과 상태가 보존되는지 확인. 기존 PTY 출력·리사이즈·종료 보장 유지.
- 실제 arm64 개발 앱: 기본 셸 자동 시작, 2개 이상의 독립 탭 및 입력/출력 격리, Pi 제출/줄바꿈, 한글 조합·취소·탭 전환, 복붙·선택·스크롤백, Retina/P10k/넓은 글자/대체 화면, 리사이즈와 `stty size`, VoiceOver, 탭/창 종료 후 소유 프로세스 회수. 자동 E2E 스위트는 만들지 않는다.
- 통과 전 Tauri 기본 경로 유지. 전환 전에 기존 작업 저장·셸 종료와 복구 기준점 확인. 복구는 이전 앱을 되돌리는 것이지 셸이나 스크롤백을 복원하는 것이 아니다.
