# 호스트 세션 — 플래닝 보고

[활성 계획](../../../../plan/host-sessions/README.md) · [보고 목차](README.md)

- 사용자 확정: 앱 종료는 detach, 탭 닫기는 종료, 재부팅은 목록만, 검증된 SSH와 계정 격리 및 탭당 단일 제어. 저장은 런타임과 카탈로그를 분리.
- 요구사항/데이터/검증(t532/t530/t531), UX/UI/데이터/테스트/보안(t533–t537) 결과 수집. 별도 모델 요청 없이 환경 기본 litellm / cli-proxy/gpt-6.2-sol로 읽기 전용 Herdr Pi 세션을 사용. 영역별 자체 리뷰는 독립 리뷰가 아니며 수정본 통합은 주 세션이 수행.
- 반영: 재접속과 종료 확인 명시, 호스트 키 오류 분리, 단일 제어 및 오래된 입력 거부, 출력 한도·잘림 표시, 메타데이터만 원자 저장. 최종 문서의 별도 독립 리뷰는 미수행.
- H0에서 근거로 백엔드를 결정. 자체 서비스나 tmux는 검증 실패의 구체적 근거가 있을 때만 검토. 운영 호스트 설정 변경·재부팅·활성 세션 중단은 승인 전 금지. 문서 작성만 완료; 구현, 후보 실증, 원격 검증 및 머지는 미수행.
