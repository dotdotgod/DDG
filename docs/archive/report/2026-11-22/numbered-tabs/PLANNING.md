# 숫자 탭과 기본 키맵 — 플래닝 완료 보고

[보관된 계획](../../../plan/numbered-tabs/README.md) · [보고 목차](README.md)

- 사용자가 숫자만 표시, 닫힌 뒤 재번호, 양끝 순환과 기존 별칭, 마지막 빈 창, README 키맵과 macOS 실기 범위를 확정했다. 고정 생성 번호와 앱 내 키맵은 선택하지 않았다.
- 요구사항·데이터·검증(t50g/t50f/t50d), UX·보안·테스트(t50h/t50j/t50k), 화면·데이터(t50m/t50n), 최종 계약(t512) 산출물을 수집했다. 역할별 별도 요청 모델 없음. Herdr Core 독립 Pi 세션의 실제 모델은 litellm / cli-proxy/gpt-6.2-sol. 영역별 디자인과 자기 리뷰는 같은 세션에서 이뤄진 경우가 있어 독립 리뷰로 간주하지 않는다. 종합 계약은 별도 세션에서 검토했고 태스크·보고는 주 세션에서 작성했다.
- 초기 합의에서는 숫자 키 직접 이동과 고정 라벨을 제외했다. 후속 사용자 요청에 따라 직접 이동은 추가한다: 1–9는 현재 표시 위치, 0만 마지막 탭이다. 없는 위치는 소비하되 선택을 바꾸지 않는다. 고정 라벨은 여전히 제외한다. 변경된 키맵·설계·검증 태스크를 함께 갱신했으며 이번 변경의 독립 재검토는 하지 않았다. 보안 검토의 클릭 대상 ID 확인과 정확한 수정키 매칭을 반영했다. 검토가 제안한 루트 README 대신 확정된 native/README.md를 키맵 원본으로 삼는다.
- 구현 시작점은 N0. 실제 Shift 괄호 디스패치와 Cmd+W 창 충돌은 미검증. 실행 시 종료 확인은 폐기 가능한 세션으로만 한다. 새 비가역 작업은 승인하지 않았다. 구현·테스트·앱 검증은 미수행, Git main 머지는 저장소 부재로 차단.
