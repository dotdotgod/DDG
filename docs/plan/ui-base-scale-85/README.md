## 요구사항과 완료 기준

- **누가·어디서:** 로컬/원격 세션을 보는 네이티브 데스크톱 사용자. 줌은 로컬 뷰어 설정이지 원격 머신이나 셸의 설정이 아니다.
- **왜·무엇을:** 숨은 배율 없이 `100%=1×`로 표시하고, 터미널만이 아니라 전체 UI의 기본 밀도를 바꾼다. 현재 보이는 화면을 다시 15% 줄이는 작업이 아니다.
- **언제:** 시작·단축키/배지 리셋·외부 설정 재로드·재시작 때 같은 의미. 기한 및 실기 담당자 미정.
- **어떻게·얼마나:** 필수 ① `BASE_UI_SCALE=0.9` 삭제 ② 각 **원래 기준값**에 `round(원값×0.85)` 정수 직접 할당(양수 0.5 올림) ③ min/max/step/default=`50/200/10/100` 유지 ④ 사용자 설정과 미커밋 변경 보존. 계산된 글꼴 advance, rem 텍스트·DPI·좌표는 정수화 대상이 아니다.
- **판정:** 충분히 넓은 창의 100%에서 rem 14, 터미널 12, 탭 바 28, 초기 사이드바 190. 50%에서 rem/터미널은 각각 7/7. 90% 저장 사용자는 12.6/10.8로 시작. 숫자 일치뿐 아니라 모달 조작, 배너/분할과 PTY 마지막 행·마우스·한글 IME 정렬도 보장한다. 1x 실기 전에는 가독성을 보장했다고 하지 않는다.
- **다음:** V1에서 격리된 실창 US-01의 증거를 수집한다. **보류/제외:** 새 환경설정, 최소 줌 상향, 별도 터미널 줌, SVG 재제작, 키맵·언어 변경, DB/네트워크/프로토콜 변경, 자동 E2E, 성능 향상 주장.

## 계약과 기존 문서의 관계

`docs/spec/requirements.md`에 고정 기준 배율 요구는 없다. `docs/plan/agent-debug-environment/README.md`의 50–200% 검증과 기존 탭 바 스냅 유지. `docs/plan/github-update-system/DESIGN_UI.md`의 160/200/520/32 및 보관된 `agent-status-icons-profiles/DESIGN_UI.md`의 185/22는 이전 기준값이다. **반응형 동작과 배너 오프셋**은 유지한다. 현행 `⌘/Ctrl+0`은 줌 리셋이고 1–9는 탭 선택이다. 과거 기록을 다시 쓰지 않는다.

`UiPrefs::load`가 외부 파일을 열어 regular/≤64 KiB/typed v2를 검사하고 `u16` 퍼센트를 clamp→snap한다. 시작 실패는 기본값(자동 저장 없음), 감시 중 invalid는 마지막 정상값, 삭제는 기본값이다. 퍼센트와 다른 v2 필드만 저장한다. `UiScale::px`는 round 후 하한 1, `term_font_px`는 하한 7. 검증 뒤 내부 스냅샷과 측정 그리드는 신뢰한다. `ui.json` 원자적 임시 파일 교체, Unix 생성 권한 파일 0600·디렉터리 0700/Windows 전용 ACL 유지. 동시 저장은 기존 마지막 교체 우선; DB·락·CAS·repair-write·검증 중복 없음.

## 역할·착수·종료

Astra: 요구·데이터·검증 기준, 별도 컨텍스트 반례 조사, F 태스크와 G 보고. Neon: C–E 설계 및 같은 세션의 역할 분리 리뷰, 반례 정정 책임. 실행 승인 뒤 Sol medium: T1 및 T2 순차. 사람/실창 검증자: V1. 실행 총괄: C1 전체 보고와 승인 경계. 호스트·터미널 경계에는 새 데이터 계약이 없다.

`R0 실행 환경·작업 트리 확인 → T1 기준값/유닛 → T2 모든 뷰/GPUI·통합 → V1 실창 → C1 종료`. 준비 작업 외에 공유 트리 병렬 편집 없음. 최종 보고·계획 이동은 전체 범위 완료 후 실행 세션의 일이다. `main` 머지·push·release는 각각 명시 승인 전 금지. 미실행·미검증 항목을 통과로 처리하지 않는다.
