## 1. 검증 원칙과 기존 필수 테스트 보존
- **TDD 적용 범위**: 아래 선정된 **유닛 테스트 22개 항목**에만 Red→Green→Refactor TDD를 적용한다(신규 TDD 19개 + 기존 필수 테스트 확장 병행 3개: `UT-PROTO-02`, `UT-HOST-01`, `UT-CLI-01`).
- **기존 필수 테스트 보존**: `ddg-agents-proto`(`openrpc_schemas_are_valid_and_up_to_date`), `ddg-terminal-server`(`core/tests`, `integration`), `ddg-agents-host`(`security_negative_boundaries`, `token_store`, `catalog_store`, `integration` 등), `ddg-agents-transport`(`profile`, `client`, `local_transport`, `docker_live`), `ddg-agents-cli`(`args`, `skill_frontmatter_and_operator_commands`, `output`, `cli_e2e`), `native`(`main`, `layout`, `ui_scale`, `machine_modal`), `ddg-agents-vt`는 삭제·생략하지 않고 `cargo test --workspace`로 유지한다.
- **미실행 보고 규칙**: macOS 로컬 환경에서 컴파일·실행되지 않는 `#[cfg(windows)]` 유닛 테스트(`UT-OS-01..03` Windows 분기, `UT-HOST-03`)는 Windows 러너/실기 실행 증거 확보 전까지 반드시 **`미검증(Windows 환경 미실행)`**으로 보고한다.

## 3. 제외된 테스트와 제외 근거
- **신규 자동화 E2E 스위트**: 역할 지침상 기본 제외(실환경은 [SCENARIOS.md](SCENARIOS.md)의 `US-01..06`으로 검증; 기존 `cli_e2e.rs`·`security_negative_boundaries.rs`는 유지).
- **단순 전달 코드 대규모 Mock/Trait(`HttpClientTrait`, `CodesignTrait` 등)**: 불필요한 DI 추상화(AI slop) 배제 — 순수 정책 함수 TDD + 실환경 시나리오 조합.
- **GPUI 픽셀/스냅샷 테스트**: Metal/DirectX 비결정성 높음 — `UT-NATIVE-01/02` + 사람 GUI 확인(`US-01`/`US-02`)으로 대체.
- **외부 크레이트 내부 알고리즘 재검증**(`sha2`, `ed25519-dalek`, `zip`/`tar`) 및 **로컬 CI 모의(`act`)**: 경계 계약과 실제 CI 러너 검증으로 대체.

## 4. 실제 환경에서만 입증 가능한 보장
1. Apple Developer ID 실서명 체인·`codesign -R`·`spctl`·CI `stapler validate`·`AppTranslocation`·`renamex_np(RENAME_SWAP)` (`US-01`).
2. `windows-latest` `ghostty-vt.lib`+GPUI 링크, Windows ConPTY+JobObject, 타 Windows 계정 DACL 차단, 2회차 `.old.<nonce>` 교체·GC (`US-02`).
3. Debian Bookworm 산출물 `glibc ≤ 2.36` 심볼 검증(`readelf -V`), 원격 Linux SSH 무중단 핸드오프·`v0.1.0` 레거시 최초 1회 업그레이드 (`US-03`).
4. 실제 GitHub Releases TLS/CDN 리다이렉트·`ETag`/`304`·Rate Limit 헤더 및 실제 `Docker` 컨테이너 무변경 (`US-04`).
